# TasteHub — Restaurant Sales Demo

TasteHub is a fictional London restaurant demo built as a client-selling template.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Unsplash image URLs
- Google Maps embed

## Pages
- `/index.html` — homepage
- `/menu.html` — full HTML menu
- `/about.html` — story
- `/gallery.html` — gallery
- `/contact.html` — reservations/contact

## Notes
- Reservation form is frontend-only and shows a confirmation message.
- Testimonials are explicitly fictional demo content.
- Replace restaurant name, images, menu, prices, contact information, opening hours, socials and map for a real client.
- Images are loaded from Unsplash over the internet; replace with licensed client imagery before production.

## Sales positioning
Use this as the base for a Restaurant Digital Presence Package: responsive website, HTML menu, gallery, reservation request flow, map, click-to-call, social links, SEO basics and deployment.
